# 理大祭 レジ・運営システム

理大祭の屋台で使う、会計・調理・受け渡し・在庫のページ集です。**自分の係の行のリンクを開いてください。**

## 係ごとのページ

| 係 | ページ | マニュアル |
|---|---|---|
| レジ担当 | [レジを開く](https://watakamashuron-png.github.io/ilab-register/) | [レジのマニュアル](https://watakamashuron-png.github.io/ilab-register/guide.html#register) |
| 受け渡し担当 | [受け渡しを開く](https://watakamashuron-png.github.io/ilab-register/?view=pickup) | [受け渡しのマニュアル](https://watakamashuron-png.github.io/ilab-register/guide.html#pickup) |
| テント調理担当 | [テント調理を開く](https://watakamashuron-png.github.io/ilab-register/?view=cook) | [テント調理のマニュアル](https://watakamashuron-png.github.io/ilab-register/guide.html#tent) |
| カナル調理担当 | [カナル調理を開く](https://watakamashuron-png.github.io/ilab-register/?view=canal) | [カナル調理のマニュアル](https://watakamashuron-png.github.io/ilab-register/guide.html#canal) |
| 出荷担当 | [出荷を開く](https://watakamashuron-png.github.io/ilab-register/?view=stock) | [出荷のマニュアル](https://watakamashuron-png.github.io/ilab-register/guide.html#stock) |

- レジは、**会計用の端末1台だけ**で使います。ほかの係は、個人のスマホで開けます。

## 困ったとき

- 画面が古いまま変わらないときは、ページを再読み込みしてください。
- 各係のQRコードは、レジの「各係用QRコード」タブにあります。
