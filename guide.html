理大祭 運営システムの全体像

はじめての人でも分かるように、図で説明します。まず全体を見てから、自分の係のページへ進んでください。

このシステムでできること

理大祭の屋台で、「会計」「調理」「受け渡し」「ロールの在庫」を、スマホとパソコンの画面で共有するしくみです。紙のやりとりを減らし、いま何本作るか、テントにロールが何本あるかが、全員にすぐ分かります。

係と画面

係ごとに、見る画面が決まっています。自分の係のページを開いてください。

レジ担当会計をする。端末は1台だけ受け渡し担当番号を呼んで渡し「提供済み」を押すテント調理担当いま作る数を見て揚げるカナル調理担当在庫と発注を見てロールを包む出荷担当発注・出荷・調整を入力する
会計係（お金の管理）
  • 売上や支出は、会計スプレッドシートで確認します。このマニュアルの対象外です。
  • レジの売上は、自動で会計スプレッドシートに集まります。

お客様への販売の流れ

ロールの在庫と発注の流れ

ロールを包むのはカナル、揚げて売るのはテントです。そのため、テントにロールが何本あるかを、出荷担当が画面で管理します。

用語

整理番号
注文ごとの番号です。札を2枚用意し、お客様と調理担当に渡します。
作成中
会計が済み、まだお客様に渡していない注文です。
提供済み
お客様に渡し終えた注文です。受け渡し担当が押します。
在庫
テントにあるロールの本数です。出荷＋調整−注文で自動計算されます。
発注
カナルにロールを頼むことです。出荷担当が画面に入れます。
出荷
カナルからテントへロールを運ぶことです。入れた時点で在庫が増えます。
調整
ロスや持越しなどで、在庫の数を直すことです。
発注の目安
在庫がこの本数以下になると、画面の色が黄色に変わります。いまは15本です。

こんなときは

画面が古いまま変わらない
ページを再読み込みしてください。画面の右上に「通信待ち」と出ているときは、電波の良い場所に移ってください。
「送信待ち」と出た
電波が戻ると、自動で送られます。送られるまで、ほかの端末への反映が遅れます。
自分の係のページが分からない
レジの「各係用QRコード」タブにある、自分の係のQRコードを読み取ってください。

レジ担当のマニュアル

お客様の会計をする係です。端末は1台だけで使います。

レジを開くhttps://watakamashuron-png.github.io/ilab-register/
はじめに
  • レジはこの端末1台だけで使います。ほかの端末でレジを開かないでください。
  • 最初に、画面の「担当を変更」で自分の名前を入れます。
  • 整理番号を使う場合は、「設定」タブで「使う」を選びます。

会計の手順

  1. 「お客様の会計を始める」を押す

    「レジ」タブにあります。

  2. 商品の個数を入れる

    「＋」「−」で、ソーセージロールとアップルティーの個数を入れます。

  3. 「合計金額を表示」を押す

    お客様向けの画面に、お支払い金額が大きく出ます。画面をお客様に見せてください。

  4. 「お預かり金額の入力へ」を押す

    お預かりした金額を入れます。ぴったりなら「ちょうど」を押します。おつりが画面に出ます。

  5. 「会計を確定」を押す

    ここで売上が記録され、調理と受け渡しの画面に注文が出ます。

  6. 整理番号の札を2枚渡す

    1枚をお客様に、もう1枚をテント調理担当に渡します。そのあと「次のお客様へ」を押します。

間違えたとき

会計全体を取り消して、やり直します
  • 確定した直後なら、完了画面の「この会計を取り消す」を押します。
  • あとからなら、「売上確認」タブの会計履歴で「取消」を2回押します。
  • 1品だけは取り消せません。取り消したあと、正しい内容で会計をやり直します。
  • 取り消した会計の整理番号は、欠番になります。

ほかのタブ

受け渡し
作成中と提供済みの一覧を、確認用に見られます。
売上確認
売上、会計数、販売数、「支出−売上」の赤字・黒字を見られます。日付で切り替えられます。
各係用QRコード
各係のスマホで読み取るQRコードが並んでいます。
設定
整理番号の使う・使わない、土曜日の「次の番号」、商品と単価を変えられます。

土曜日の朝にすること

整理番号を決める
  • 「設定」タブで、土曜日の「次の番号」を、金曜日の続きにするか1に戻すか決めて入れます。

電波が悪いとき

会計は止まりません。売上は端末に残り、電波が戻ると自動で送られます。画面の右上が「送信済み」なら、すべて送れています。

受け渡し担当のマニュアル

番号を呼んで商品を渡し、「提供済み」を押す係です。

受け渡しのページを開くhttps://watakamashuron-png.github.io/ilab-register/?view=pickup

画面の見方

作成中
会計が済んで、まだ渡していない注文です。古い順に並びます。10分以上たつと、色が変わって知らせます。
完了
渡し終えた注文です。押し間違えたときは、ここから戻せます。

手順

  1. 「作成中」の一覧を見る

    整理番号と、注文の内容（商品と個数）が出ています。

  2. 揚げ上がった注文の番号を呼ぶ

    テント調理担当から受け取ったものと、お客様の札の番号を合わせて確認します。

  3. 商品を渡す

    札と交換して、商品を渡します。

  4. その注文の「提供済み」を押す

    注文が「完了」に移ります。テント調理の画面から消え、カナルの画面の「出た数」に加わります。

押し間違えたとき
  • 「完了」の一覧で、その注文の「作成中に戻す」を押します。
電波が悪いとき
  • 画面に「送信待ち」が出ている間は、押した内容がまだ送られていません。電波が戻ると自動で送られます。
  • 「通信が途絶えています」が出たら、ページを再読み込みしてください。
何人で使ってもいい？
はい。受け渡し担当それぞれのスマホで開けます。同じ注文を2人が押しても問題ありません。

テント調理担当のマニュアル

注文を見て、ソーセージロールを揚げ、アップルティーを用意する係です。

テント調理のページを開くhttps://watakamashuron-png.github.io/ilab-register/?view=cook

画面の見方

いま作る数
作成中の注文の合計です。ソーセージロールは本、アップルティーは杯で出ます。この数を目安に作ります。
作成中の一覧
注文ごとの整理番号と内容が、古い順に並びます。10分以上たつと色が変わります。

この画面は見るだけです。ボタンはありません。

手順

  1. レジ担当から整理番号の札を1枚受け取る

    お客様に渡す札と同じ番号です。

  2. 「いま作る数」を見て揚げる・用意する

    画面は5秒ごとに自動で更新されます。

  3. 揚げ上がりを受け渡し担当へ渡す

    受け渡し担当が、番号を呼んで商品をお客様に渡します。

在庫が少ないとき
  • ロールが少なくなったら、出荷担当に声をかけてください。
  • 在庫の数は、出荷担当の画面とカナルの画面に出ています。
  • 出荷担当と相談して、カナルへ発注します。
画面が変わらないとき
  • ページを再読み込みしてください。
  • 「通信が途絶えています」が出ているときは、表示が古い可能性があります。

カナル調理担当のマニュアル

ロールを包む係です。テントの在庫と、発注を画面で確認します。

カナル調理のページを開くhttps://watakamashuron-png.github.io/ilab-register/?view=canal

画面の見方

テント在庫
テントにあるロールの本数です。緑は「足りています」、黄色は「発注の目安（15本以下）」、赤は「売りすぎです（足りません）」です。
発注中
出荷担当が頼んだ本数と、頼んでからの時間です。出荷されると消えます。
発注の履歴
頼んだ本数を、新しい順に並べています。「発注中」と「出荷済み」で見分けます。
出荷・調整・注文・提供済み・作成中
在庫の内訳です。注文は、会計が確定した本数です。
出た数
お客様に渡し終えた商品の合計です。

この画面は見るだけです。ボタンはありません。

手順

  1. 「発注中」の本数を確認する

    出荷担当が発注すると、黄色の帯に本数が出ます。

  2. その本数のロールを包む

    赤の「売りすぎです」が出ているときは、急いで用意します。

  3. 出荷担当に渡す

    出荷担当がテントへ運び、出荷を入力します。入力すると、発注中の表示が消えます。

発注が来ないとき
  • 在庫が黄色や赤なのに「発注中」が出ていないときは、出荷担当に声をかけてください。
  • 画面は5秒ごとに自動で更新されます。更新時刻が止まっているときは、ページを再読み込みしてください。

出荷担当のマニュアル

テントとカナルを行き来して、発注・出荷・調整を入力する係です。

出荷のページを開くhttps://watakamashuron-png.github.io/ilab-register/?view=stock

画面の下に、4つのタブがあります。

在庫
テント在庫、発注の目安、担当を交代するときの確認が見られます。
発注
カナルにロールを頼みます。
出荷
カナルからテントへ運ぶ本数を入れます。
調整
ロスや持越しなどで、在庫を直します。

ふだんの流れ

  1. 「在庫」で在庫を確認する

    テントの人と相談して、発注するか決めます。

  2. 「発注」で本数を入れ、「発注する」を押す

    カナル調理担当の画面に「発注中」が出ます。

  3. ロールを受け取り、テントへ運ぶ

    運ぶ直前に、次の手順を済ませます。

  4. 「出荷」で本数を入れ、記録する

    入れた時点で、テント在庫が増えます。その日の発注は、自動で「出荷済み」になります。

気をつけること
  • 発注が2件あるときに出荷を1回入れると、2件とも「出荷済み」になります。足りない分は、もう一度発注してください。
  • 在庫は「出荷＋調整−注文」で計算されます。注文は、会計が確定した時点で数えます。

間違えたとき

発注・出荷・調整は、すべて取り消せます
  • それぞれのタブの記録で、「取消」を2回押します。
  • 発注を取り消しても、在庫の本数は変わりません。
  • 出荷を間違えたときは、「出荷」タブの記録を取り消します。在庫が元に戻ります。

調整のしかた

増減を入れる
理由（ロス・持越し・数え直し）を選び、「増やす」か「減らす」で本数を入れます。
実数にそろえる
いま数えたロールの本数を入れると、差を自動で調整として記録します。作成中の注文があるときは、揚げ待ちの分を引いて入れてください。

日にちごとの作業

土曜日の朝
  • 前日からの持越しを、「調整」タブで入れます。理由は「持越し」、「増やす」を選びます。
閉店後
  • 揚げる前のロールを数え、「調整」タブの「実数にそろえる」に入れます。差がロスとして記録されます。
担当が交代するとき
  • 記録はすべてサーバーに保存されています。新しい端末で、このページを開くだけで続けられます。
  • 交代する前に、「在庫」タブに「送信待ち」が出ていないことを確認してください。
  • 「在庫」タブの「発注の目安」は、全端末で共通の設定です。
